# 保留经典玩法，新增模式可选

用户纠正：能量雨、成长及天平仅作为新增模式，不能替代原玩法。沿用直接实现和提交推送授权。

设计：房间 mode 为 classic/energy，默认 classic。classic 不生成能量、体型固定、所有平台按静态处理，恢复原固定地面的摩擦参数。energy 显式开启能量雨、成长与天平。地图数据与模式分开，切换不会删除自定义天平属性；原三张地图、计分、空格加重和旋转编辑保留。随机生成按当前模式选择固定或动态平台。房主仅在 lobby 切换，广播给成员和后加入者，比赛期间锁定；新房间独立默认 classic。试跑模式独立可选，默认当前房间或首页 classic，不隐式改变房间模式。
